# 17: Command Center: month-to-date and historical views

**What to build:** In Command Center, a Superuser can switch from the daily view to month-to-date and historical views, and compare Brands and Portfolios over those longer horizons.

**Blocked by:** 16 (Command Center: daily view)

**Status:** ready-for-agent

- [ ] Command Center has daily, month-to-date and historical views.
- [ ] The month-to-date view shows totals, pacing and month forecast for each Brand and Portfolio.
- [ ] The historical view lets the Superuser choose how many months to show.
- [ ] The views handle any number of Portfolios, keep the card order from 16, and follow the same totals rule and mixed-dates warning.
- [ ] `SprygKit` tests with recorded JSON cover both views, including more than one Portfolio.
